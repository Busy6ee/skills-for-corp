# Chisel Book

- **Source URL**: https://github.com/schoeberl/chisel-book.git
- **License**: Simplified BSD License
- **Import Date**: 2026-03-22
- **Chisel Version**: 6.5.0 (Scala 2.13.14)
- **Imported Skills**:
  - `chisel-project`: 프로젝트 셋업, build.sbt, Verilog 생성, BlackBox
  - `chisel-basics`: 모듈/타입/IO 정의, 조합논리 패턴
  - `chisel-testing`: ChiselTest 테스트벤치 패턴
  - `chisel-fsm`: 유한 상태 머신 (Mealy/Moore, FSM+datapath)
  - `chisel-memory`: SyncReadMem, 레지스터 파일, 포워딩
  - `chisel-interface`: DecoupledIO, Flipped, bulk connection, 프로토콜
  - `chisel-generator`: 파라메트릭 하드웨어, 제네릭, 함수형 패턴
  - `chisel-components`: FIFO, UART, 카운터, 디바운스 등 빌딩블록
- **Modifications**: 코드 예제를 스킬 레퍼런스 형식으로 재구성, AI 코드 생성 특화 gotcha 추가
- **Excluded Content**: LaTeX 본문, 슬라이드, 그림, 스크립트, leros/soc/wildcat 서브시스템, 형식 검증
